# 战斗规则（RULES）

本文是战斗数值的唯一权威定义。代码实现与本文不符即为缺陷。

## 1. 角色属性

| 属性 | 含义 |
|---|---|
| `hp` | 当前生命值，整数 |
| `atk` | 攻击力，整数 |
| `armor` | 护甲，整数 |
| `speed` | 速度，整数，决定出手顺序 |
| `pierce` | 护甲穿透，整数，默认 0 |
| `crit` | 本次攻击是否暴击，布尔 |

## 2. 护甲穿透与有效护甲

```
有效护甲 = max(0, 护甲 - 穿透)
```

有效护甲**不允许为负**。穿透高于护甲时，多出的部分不转化为额外伤害。

## 3. 基础伤害

```
实际攻击力 = atk + 10 × 攻击增益层数
基础伤害   = 实际攻击力 × 技能倍率 ÷ 100，向下取整（整除）
```

向下取整，不得四舍五入，也不得使用浮点数参与中间计算。

## 4. 伤害结算顺序

```
减免后伤害 = max(1, 基础伤害 - 有效护甲)
最终伤害   = 暴击 ? 减免后伤害 × 2 : 减免后伤害
```

**顺序不可调换**：必须先扣除护甲，再计算暴击翻倍。最低伤害为 1。

## 5. 攻击增益（attack_up）

- 每层提供 `+10` 攻击力。
- **最多 3 层**，超过 3 层不再增加。
- 重复施加时层数 +1（上限 3），并把剩余回合数刷新为 2。
- 剩余回合数归零时，一次性清除全部层数。

## 6. 出手顺序

- 按 `speed` 从高到低排序。
- `speed` 相同时，按角色**加入战斗的先后顺序**（稳定排序），不得按名字或 ID 排序。

## 7. 死亡

- `hp <= 0` 的角色立即退场，本回合及后续回合都不再行动。
- 一方全部退场即战斗结束，判定另一方获胜。

## 8. 验收方式

- 任意给定一组角色与技能倍率，按本文手算的伤害与实际伤害一致。
- 同速角色出手顺序与加入顺序一致。
- 增益层数在任何操作序列下都不超过 3。
